Reboot CSS

La première partie du CSS cde bootstrap est un "reboot", c'est un dire toute une partie CSS qui permet de remettre en mode web et accessible les éléments normalement couvert par le CSS du navigateur, qui n'est pas accessible par défaut.

La police de caratère est modifiée, passant d'une police à empatement non adaptée à l'affichage à l'écran par une police sans empatement. La taille de la police par défaut est augmentée ainsi que l'interligne.

Tous les éléments sont par défaut mis en calcul de taille avec les bordures, alors que le CSS navigateur gère les tailles des éléments par leur contenu. De plus, la marge extérieure de body est supprimée.

Premièrement, il gère les titres, puis les paragraphes sont modifiés.

Les liens sont modifiés.

Les media

Pour rendre les media adaptatifs, Bootstrap propose des classes adaptées.

Pour les images, la classe "img-fluid" permet d'afficher l'image jusqu'à 100% de sa largeur, mais elle ne s'affichera jamais plus grande que sa taille originale.

Il est aussi possible de combiner cette classe et la balise picture

Il est possible d'utiliser une classe qui met les images en mode "vignette", avec une petite bordure blanche autour et aussi de faire "flotter" cette vignette à gauche avec "float-start" ou à droite avec "float-end"

On peut aussi centrer l'image à l'aide de la classe "mx-auto" et "d-block"

Classe mx-auto intégrée à un élément déjà en display: block; Une div.

Les vidéos peuvent aussi être intégrées à l'aide de classe pour les rendre adaptatives.

Si la vidéo est hébergé sur le site, on utilise la classe "img-fluid" dans la balise <video>

Dans le cas de vidéo hébergée sur une site tier, tels que youtube, viméo ou dailymotion, il faudra selon certain cas faire quelques ajustement.

Les vidéos sont partagées grace à une balise <iframe> qui permet d'importer dans la page une autre page. Sur les sites d'hébergement de vidéos, une page particulière est partageable via une iframe, la vidéo est ensuite appelée dedans.

Youtube

Quand vous partager une vidéo youtube, vous obtenez généralement le code suivant : 

<iframe width="560" height="315" src="https://www.youtube.com/embed/j-Chh4SRjwE?si=uCwb_GBtQdvl2mHh" title="YouTube video player" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" referrerpolicy="strict-origin-when-cross-origin" allowfullscreen></iframe>

Il est donc interressant d'utiliser une iframe mais qui sera encapsulée dans un conteneur, une figure, et à cette figure on ajoute deux classes bootstrap : ratio et ratio-16x9 par exemple pour une vidéo 16 / 9ème

Dans cette figure, il suffit de coller l'iframe donnée par youtube en retirant les attributs width et height
